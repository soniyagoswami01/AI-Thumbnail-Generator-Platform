# AI Thumbnail Generator Platform

A full-stack AI-powered thumbnail generation platform developed using React, Node.js, Express, and MongoDB. The application allows users to generate customizable thumbnails with live preview functionality, authentication, and workflow management features.

## Features

* AI-powered thumbnail generation
* Custom templates
* Live preview functionality
* JWT authentication
* Responsive UI
* Thumbnail history management
* Modular backend architecture

## Tech Stack

* React
* JavaScript
* Node.js
* Express.js
* MongoDB
